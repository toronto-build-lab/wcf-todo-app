# TodoWeb Client (Legacy)

This directory contains the legacy ASP.NET Web Forms web application that targets .NET Framework 4.7.2.

## Background
- Crucial dependency on Windows, IIS, and full .NET Framework.
- Relies on classic `.aspx` page markups and WCF service-references (`Connected Services/ServiceReference`).
- Kept here purely for archeological and reference purposes to demonstrate contract compatibility with the modernized `TodoWCFService`.
